Direct instruction with questioning: what segmentation is

Network segmentation

Dividing one network into smaller, separate parts (segments), so that traffic stays inside its segment and anything that crosses between segments passes a boundary device (router, Layer 3 switch or firewall) where it can be checked or blocked.

Performance, because...

each segment is a smaller broadcast domain: a broadcast stays inside its own segment, so each device receives less traffic and congestion falls.

Security, because...

a breach is contained in one segment; access to a sensitive segment is restricted; an attacker cannot move freely, so the attack surface is smaller.

Management, because...

each group gets its own rules, and a fault is found and fixed inside one segment, not the whole building.

Common exam mistake: giving only the security reason.

Toolkit, 4 minutes: what is inside an IP address

A network part and a host part

10.20.30.15

Network part: which network (subnet) the device is on. Like the street name.

Host part: which device inside it. Like the house number.

The subnet mask tells a device where the network part ends. You do not calculate it.

A subnet = one range of addresses

10.20.30.1 to 10.20.30.254  Staff
10.20.40.1 to 10.20.40.254  Students

Same network part: same subnet. Different network part: different subnet.

Are 10.20.30.15 and 10.20.30.200 in the same subnet?

Yes: same network part, 10.20.30.

Are 10.20.30.15 and 10.20.40.15 in the same subnet?

No: the host parts match, but the network parts differ.

A student laptop sends a broadcast. Who receives it?

Only the student subnet. The router stops it: each subnet is its own broadcast domain.

A student laptop tries to open a staff PC. What happens?

It must go through the router, where a firewall rule can block it.

Why put all the cameras in one subnet?

One rule for the whole group, their video stays local, and the address space stays organized.

Direct instruction with questioning: VLANs

A VLAN groups devices by function, not by floor

-
Sf StaffSt StudentsFi FinanceCa CamerasGu Guests

Finance is on floors 2 and 3. How is it one network?

Their switch ports are set to the same VLAN. The link between switches carries a VLAN tag on each frame.

A guest and a staff PC share a switch. Can they talk?

Not directly: different VLANs. Only through the router or Layer 3 switch, where the firewall decides.

A teacher moves to floor 3. What changes?

One port setting on the switch. No new cable.

Spot the difference: subnetting or VLAN?

Two tools, same goal, different layers

SubnettingVLAN
Divides the network byIP address rangeFunction, on the switches, wherever the device is
TCP/IP layerInternet layer (packets)Network interface layer (frames)
Set up onRouters and Layer 3 switchesManaged switches, in software
Crossing between two of themAlways through a router or Layer 3 switch, where firewall rules apply
In a real networkUsed together: each VLAN gets its own subnet. Segmenting is the overall strategy that decides where the boundaries go.

So is segmenting always worth it? What does it cost?

Complexity: every switch, VLAN and firewall rule must be configured by someone skilled. Mistakes block legitimate traffic (the teacher who cannot reach the printer). Maintenance: every new department or device type means updating the design.

Exam technique, 4 minutes: explain means "because"

Explain how network segmentation improves security. [4]

Answer A

"Segmentation makes the network more secure because it splits it up, so hackers find it harder and data is safer."

1 mark at most: it says the network is split, but never how that stops an attacker.

Answer B

"Segmentation isolates parts of the network from each other, so if one segment is compromised the router or firewall at the boundary stops the attack spreading and the damage is contained. Access to a sensitive segment, such as finance, can be limited to authorized devices. Because an attacker cannot move freely across the whole network, the attack surface is smaller."

4 marks: isolation, containment at the boundary, restricted access, smaller attack surface.
