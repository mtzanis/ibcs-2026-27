Part 1 · A2.2.1Network topologies

The shape of a network

A topology is the layout of how the devices (nodes) in a network are connected. It decides what happens when a link fails, how much cabling is needed and how easy the network is to grow.

TopologyStrengthsWeaknessesTypical use
StarEasy to add or remove a node. A broken cable affects only one node. Faults are easy to find.The central switch is a single point of failure. Needs a cable from every node to the centre.Most office and school LANs
MeshSeveral routes between nodes, so no single point of failure. Traffic can be spread across paths.A full mesh of n nodes needs n(n−1)/2 links, so cost and complexity grow fast.Internet backbone, links between core routers, wireless mesh
HybridEach part uses the topology that suits it, balancing cost against reliability.More complex to design, document and manage.Campuses, hospitals, large organizations

A partial mesh links only some nodes to several others. It keeps most of the reliability of a full mesh at much lower cost, which is what real backbones use.

Four quick checks. Give yourself the reason before you click.

Part 2 · A2.2.2Servers HL ONLY

Which server does which job?

A server is a computer, or a program on one, that provides a service to clients when they ask for it. One physical machine can run several server roles.

ServerWhat it doesExample
DNSTranslates domain names into IP addresses. If it doesn't know an address, it asks other DNS servers, then caches the answer.bbc.co.uk → 151.101.0.81
DHCPGives each device an IP address automatically when it joins, plus the subnet mask, default gateway and DNS server. Addresses are leased for a set time, then reused.Your laptop joins the school Wi-Fi and gets 10.20.4.57
WebStores web pages and sends them to browsers that request them, using HTTP or HTTPS.The school website
FileStores files centrally so users can share them. Access rights and backups are managed in one place.Shared drive for department resources
MailStores users' email and passes outgoing messages on to other mail servers.Staff and student email
ProxySits between users and the internet. Forwards requests, filters blocked sites, caches popular pages and hides internal addresses.The school web filter

Link to A2.4: a server that everyone depends on (DNS, DHCP, the web server) is also a target. Knock it offline and the whole network stops working.

Part 3 · A2.2.3Network models

Client–server or peer-to-peer?

A network model describes how devices share work and resources. In client–server, dedicated servers provide services and clients request them. In peer-to-peer (P2P), every device has equal status and can act as both a client and a server.

Client–serverPeer-to-peer
ControlCentral: accounts, access rights and updates in one placeEach user manages their own device and what it shares
SecurityEasier to enforce and auditOnly as good as the weakest peer
BackupsDone centrally, on the serverEach peer backs up its own files, or nobody does
CostHigher: server hardware, software, technical staffLow: uses existing computers, quick to set up
ScalabilityGrows by upgrading or adding serversHard to manage as peers increase (but large P2P apps share the load well)
If one machine failsServer down: every client loses that serviceOnly that peer's resources are lost
ExamplesSchool network, email, websites, online bankingSmall home networks, BitTorrent, blockchain

Both models share files and resources over a network and use the same hardware and protocols. You need those similarities for a "compare and contrast" question.

Part 4 · A2.2.4Segmentation, recap

Walls inside the network

You covered this in the A2.2.4 Segmentation Workbench; go back to it if anything here feels new. The short version:

  • Segmentation divides one network into smaller, separate segments. Traffic stays inside its segment; anything crossing between segments goes through a router, Layer 3 switch or firewall, where it can be checked or blocked.
  • Subnetting divides the network by IP address range. Each subnet is its own broadcast domain, and routers do not forward broadcasts. You need what it is for, not how to calculate it.
  • VLANs group switch ports into separate logical LANs by function, wherever the devices physically are. One managed switch can carry several VLANs.
  • Two benefits, always: performance (smaller broadcast domains, less congestion) and security (a breach is contained; no lateral movement). Plus management: rules per group, faults contained.

Part 5 · Mini testScenario: Northpoint Hotel

Northpoint Hotel has four floors. It has:

  • 25 staff PCs at reception and in the offices, connected by cable to a switch on each floor.
  • A booking system on a server in the basement, used by reception, the hotel website and the cleaning team's tablets.
  • Guest Wi-Fi for up to 300 guest devices.
  • Smart door locks on all 120 rooms, which are currently on the same network as the guest Wi-Fi.
